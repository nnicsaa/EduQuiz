EDUQuiz is a simple web-based platform built with HTML, CSS, JavaScript, PHP, and MySQL. It is designed to make taking and managing quizzes easy for both students and administrators.

Students can use the platform to take multiple-choice quizzes, view their past scores, customize their profiles, and compete on a leaderboard. Meanwhile, administrators have a dedicated dashboard where they can create or delete quizzes, add questions, manage student accounts, and view performance reports.

To run the project locally, you will need to install XAMPP and start Apache and MySQL. Place the project folder inside your XAMPP htdocs folder, create a new database in phpMyAdmin, and import the provided SQL file to set up the tables.
